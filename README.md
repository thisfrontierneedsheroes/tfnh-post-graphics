# TFNH post graphics

Finished graphics for social posts (This Frontier Needs Heroes, Americana Barcelona).
Buffer and other scheduling tools pull images from here by direct link.

**Everything in this repository is public.** Only finished, ready-to-post graphics go here —
never masters, contracts, unreleased music, or anything private.

Layout: `YEAR/campaign/YYYY-MM-DD-short-name.jpg`

Direct image link format:
`https://raw.githubusercontent.com/thisfrontierneedsheroes/tfnh-post-graphics/main/<path>`
